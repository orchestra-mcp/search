# @orchestra-mcp/search

Search spotlight component for Orchestra MCP

Part of the [Orchestra MCP](https://orchestra-mcp.dev) ecosystem.

## Install

```bash
npm install @orchestra-mcp/search
# or
pnpm add @orchestra-mcp/search
```

## Usage

```tsx
import { } from '@orchestra-mcp/search'
```

## Requirements

- React >= 18.0.0
